# Stonoga FX

Przester / fuzz do noise rocka (VST3 + wersja samodzielna) na Windows i Mac.

## Pobieranie
Zakładka **Actions** → ostatni udany przebieg „Build Stonoga FX” → sekcja *Artifacts* → `StonogaFX-Windows`.

* `Stonoga FX.vst3` skopiuj do `C:\Program Files\Common Files\VST3\`
* `Stonoga FX.exe` (Standalone) uruchamia efekt bez DAW — wybierz w ustawieniach interfejs audio z gitarą.

## Pokrętła
| | |
|---|---|
| **Przester** | 6–72 dB kaskadowego przesteru; powyżej ~70% sygnał zaczyna się zawijać (wavefolding) |
| **Głód baterii** | niższe i asymetryczne napięcie: charczenie, spłaszczenie, zrywanie |
| **Rozpad (bramka)** | bramka, która przy wybrzmiewaniu rwie dźwięk na strzępy (velcro) |
| **Oktawa** | oktawa w górę z prostowania sygnału |
| **Maska** + **Samogłoska** | nosowy filtr formantowy u‑o‑a‑e‑i, otwiera się mocniejszym atakiem |
| **Rdza** | bitcrush i decymacja — metaliczne, aliasujące tony |
| **Trzaski** | trzaski zależne od siły gry |
| **Sprzężenie** + **Czas** | wewnętrzne sprzężenie zwrotne; od ~40% samo piszczy |
| **Barwa** | ciemno ↔ jasno |
| **Mix**, **Wyjście** | |

Presety: Mięso, Zdychająca bateria, Maska nō, Rdza, Sprzężenie, Totalny rozpad.

Uwaga: przy dużym sprzężeniu efekt może grać sam — zacznij od niskiej głośności.
