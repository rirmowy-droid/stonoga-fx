# Stonoga FX

Przester / fuzz do noise rocka (VST3 + wersja samodzielna) na Windows i Mac.

## Pobieranie
**[Najnowsze wydanie](https://github.com/rirmowy-droid/stonoga-fx/releases/latest)** → `StonogaFX-Setup.exe` → uruchom.

* Wtyczka VST3 trafia do `C:\Program Files\Common Files\VST3\` — w DAW zrób ponowne skanowanie wtyczek.
* „Stonoga FX (bez DAW)” w menu Start uruchamia efekt samodzielnie — wybierz w ustawieniach interfejs audio z gitarą.
* Instalator nie jest podpisany, więc Windows może ostrzec: „Więcej informacji” → „Uruchom mimo to”.

## Pokrętła
| | |
|---|---|
| **Przester** | 6–72 dB kaskadowego przesteru; powyżej ~70% sygnał zaczyna się zawijać (wavefolding) |
| **Głód baterii** | niższe i asymetryczne napięcie: charczenie, spłaszczenie, zrywanie |
| **Rozpad (bramka)** | bramka, która przy wybrzmiewaniu rwie dźwięk na strzępy (velcro) |
| **Oktawa** | oktawa w górę z prostowania sygnału |
| **Maska** + **Samogłoska** | nosowy filtr formantowy u‑o‑a‑e‑i, otwiera się mocniejszym atakiem |
| **Rdza** | bitcrush i decymacja — metaliczne, aliasujące tony |
| **Trzaski** | trzaski zależne od siły gry |
| **Sprzężenie** + **Czas** | wewnętrzne sprzężenie zwrotne; od ~40% samo piszczy |
| **Wycie** | sprzężenie jak gitara przy wzmacniaczu: dostraja się do granej nuty, narasta przy wybrzmiewaniu i skacze po alikwotach; wyciszenie strun je gasi |
| **Pogłos 1 (śpiew)** + **Rozmiar 1** | pierwszy pogłos, od pokoju do 20‑sekundowej katedry; to jego ogon śpiewa i ma chór |
| **Pogłos 2 (jasny)**, **Pogłos 3 (otchłań)** + rozmiary | dwa kolejne pogłosy w szeregu: drugi dostaje wszystko z pierwszego, trzeci wszystko z drugiego |
| **Chorus** + **Tempo** | trzy głosy, lewy i prawy kanał w przeciwnych fazach |
| **Miękkość** | ciepły, lampowy overdrive zamiast kaskadowego fuzzu |
| **Mgła** | nuty narastają po pauzie (shoegaze) |
| **Pełnia** | więcej dołu i podoktawa pod spodem |
| **Śpiew** | ogon pogłosu śpiewa: filtry samogłosek + rezonans na wysokości granej nuty |
| **Chór** | oktawa i kwinta w pętli pogłosu — ogon unosi się w nieskończoność |
| **Pętla pogłosu** | pogłos wraca do przesteru: samopodtrzymująca się ściana |
| **Barwa** | ciemno ↔ jasno |
| **Ochrona uszu** | gdy pojawia się bzyczenie lub pisk, płynnie przyciemnia górę; gdy dźwięk długo jest za głośny (np. rozpędzone sprzężenie), powoli ścisza; na wyjściu zawsze działa limiter −1 dB |
| **Mix**, **Wyjście** | |

Presety: Mięso, Zdychająca bateria, Maska nō, Rdza, Sprzężenie, Wycie, Chór umarłych, Utonięcie, Ciepły crunch, Shoegaze, Ściana mgły, Trzy katedry, Totalny rozpad.

Uwaga: przy dużym sprzężeniu efekt może grać sam — zacznij od niskiej głośności.
